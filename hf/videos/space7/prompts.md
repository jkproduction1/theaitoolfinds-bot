# space7 prompts — DM for comment SPACE
Save each as a Claude Code command (.claude/commands/<name>.md, "$ARGUMENTS" = your idea) or paste it directly.

/zack-d-films — A 6-second vertical (9:16) "what if" 3D short about $ARGUMENTS, ONE self-contained HTML file with three.js and a
deterministic render(t). Stylised 3D with real volume (soft materials, one hard key light, a cool rim light, real shadows), a low
cinematic camera that slowly pushes in, one bold caption at the top with the key fact in a highlight box. Textbook facts only, and SHOW
them: e.g. on the Moon gravity is about 1/6 of Earth's and there's no air, so the jump is slow and high and the dust flies in clean arcs.

/explain-3d — A 9:16 3D explainer of $ARGUMENTS in one HTML file (three.js, render(t), ~6 s). Decide the key parts and the one thing that
moves between them, build them from primitives with care, animate the mechanism with physically plausible speeds, pop in short name
tags one by one, slow camera move from a side view to an overview. Caption: max 7 words, one highlighted key word. No invented numbers.

/deep-dive — A cinematic 9:16 3D deep dive into $ARGUMENTS (three.js, one HTML file, render(t), ~6 s): dark space, a dramatic hero shot,
glowing additive materials for energy and light, a slow orbiting camera, 3 labels in one column with leader lines (bold name + short
mono sub-line), caption with one highlighted word. For a black hole: a black event horizon, a hot accretion disk spiralling in, a star
that gets too close is stretched into a stream and swallowed. Textbook facts only.
