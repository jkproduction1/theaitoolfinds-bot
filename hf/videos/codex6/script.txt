Most people use Codex CLI like a chat box. These six commands change that. One: slash review. It reviews your current changes and finds issues. Two: slash side starts a side chat in a throwaway fork. Three: slash fork splits the chat, so you can try another path. Four: slash diff shows your git diff, even untracked files. Five: slash init writes an AGENTS file with instructions for Codex. Six: slash import brings your setup and recent chats over from Claude Code. Comment CODEX and I'll send you the full list.
