# earth8 prompts — DM for comment PLANET
Save each as a Claude Code command (.claude/commands/<name>.md, "$ARGUMENTS" = your idea) or paste it directly.

/zack-d-films — A 6-second vertical (9:16) "what if" 3D short about $ARGUMENTS, ONE self-contained HTML file with three.js and a
deterministic render(t). Stylised 3D with real volume (soft materials, one key light, real shadows), a low cinematic camera with a
little shake on impact, one bold caption at the top with the key fact in a highlight box. Textbook facts only, and SHOW them: e.g. if
Earth stopped spinning, the ground stops but everything on it keeps moving east (up to ~1,670 km/h at the equator), then the oceans follow.

/deep-dive — A cinematic 9:16 3D deep dive into $ARGUMENTS (three.js, one HTML file, render(t), ~6 s): a cross-section slice drawn to
scale (1 unit = 1 km), the camera dives down with a small light while a depth gauge counts, then pulls back to the full picture with
2–3 labels in one column (bold name + short mono sub-line). Use a familiar object for scale (e.g. Mount Everest, 8,849 m, inside the
Challenger Deep, ~10,935 m). Textbook numbers only.

/scale — A 9:16 true-to-scale size comparison of $ARGUMENTS (three.js, one HTML file, render(t), ~6 s): both objects pop in side by side
at real proportions with name + size labels, one visual "how many fit" beat with a counter, then a dramatic camera pull-back to the real
distance or context. E.g. Moon 3,474 km vs Earth 12,742 km wide, ~49 Moons by volume, ~384,400 km apart. Real numbers only.
