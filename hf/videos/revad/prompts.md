# revad — prompt for the on-camera Claude Code session (paste into the Code tab)

Build a 13-second landscape (1920x1080) product film for Revolut, all in code: three.js for 3D (phone, metal card, payment terminal),
HTML/CSS for the app UI, one timeline function window.setT(t) so every frame renders deterministically.
Story "Money that travels with you.": the app listing slides in and a finger taps Get → the button grows into black → a 3D phone
lands on the lock screen "Welcome to New York · Exchange at the real rate" → match cut into an exchange-rate chart (EUR→USD draws
on, the rate ticks up) and an exchange card where €500 becomes $542.10 → a metal card spins in, shows its details and taps a payment
terminal, contactless rings, "Paid $4.50 · Coffee" → white beat "Spend like a local." → the USD balance counts down as Coffee,
Metro and Hotel slide in → end card: Revolut, "Money that travels with you."
Palette: near-black #07070A, warm white #F6F6F4, blue→violet gradient #3D5AFE→#8B5CF6, mint #7ee2b8 only for money in.
Inter Display. Expo-out arrivals, soft springs on UI, finger taps (press + ripple, never a mouse), purple light behind 3D objects,
subtle grain. No logos: the brand name only as plain text. Fictional card numbers.
