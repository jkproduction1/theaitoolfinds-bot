# zoom3 prompts — DM for comment ZOOM
Save as Claude Code commands (.claude/commands/<name>.md, "$ARGUMENTS" = your topic) or paste directly.

/zoom-in — Make a 9:16 full-screen animation (canvas or three.js, rendered frame by frame with HTML + GSAP, ~4 s) that zooms into
$ARGUMENTS continuously until you see what it is built from. Exponential zoom on one interesting point, the structure appears as
you get closer. Labels with leader lines, a short caption word by word with one key word in a blue box. No invented numbers.
  Example: /zoom-in my phone screen  (image → pixels → red, green and blue subpixels)

/explain-3d — Cinematic 3D explainer of $ARGUMENTS: build the object as a clean cutaway, then animate the mechanism that makes it work.
Real studio HDRI light, bloom, depth, labels and captions as above.
  Examples: /explain-3d how a lock opens  (pin tumbler: the right key lifts every pin to the shear line, the plug turns)
            /explain-3d how a watch ticks  (balance wheel swings, escapement releases the gears one tick at a time, mainspring powers it)
